# Drone Remote ID Real-Time Tracking Prototype

This repository contains the source code for the Drone Remote ID Real-Time Tracking Prototype developed as part of a Bachelor's thesis at Seinäjoki University of Applied Sciences (SeAMK).

## Overview
The system captures and parses ASTM F3411-22a compliant Remote ID broadcast packets encapsulated in TZSP streams from MikroTik RouterOS hardware. It provides an integrated, real-time tracking display designed to enhance low-altitude situational awareness for Aerodrome Flight Information Service (AFIS) controllers and drone testing teams at Seinäjoki Airport.
